== ONTAP data server

There are several requirements and restrictions for the ONTAP data servers used with Novus. For the initial product release, it is an ONTAP-based AFF platform with Novus-specific hardware enhancements and a constrained software and configuration profile. The supported design is intentionally limited at launch with the major requirements and limitations explicitly identified.

AFF A90 for NetApp Novus::
This is an AFF A90 system configured specifically for Novus and used as the _ONTAP data server_ in a Novus deployment. Each AFF A90 for NetApp Novus is a two-node, switchless ONTAP HA pair with dual NVRAM and 400GbE host networking.

ONTAP details::
Novus ONTAP data servers run a customized version of ONTAP 9.19.1.

Licensing::
Novus uses ONTAP One. No additional licensing is required.

NVRAM and base hardware::
The ONTAP data server requires two NVRAM cards rather than the standard single-card configuration. The system must use the AFF for Novus hardware build, including a factory configuration that identifies the dual-NVRAM ONTAP data server variant.

Network hardware::
The ONTAP data server requires CX-7 network cards supporting 400G front-end, 400G HA back-to-back, and 100G cluster back-to-back connectivity.

Cluster size and HA::
The supported ONTAP data server deployment is a single HA pair, implemented as a two-node switchless cluster.

SVM requirement::
Support is limited to one data SVM per cluster.

Protocols::
The ONTAP data path supports NFSv3 only. Other protocols (NFSv4, SMB, S3, SAN protocols) are not supported on the ONTAP data path in the initial release.

== Novus Data Director

The Novus Data Director (NDD) is an implementation of the metadata server (MDS) as defined in the Parallel NFS (pNFS) architecture. It's a software-defined package running on properly configured server.

[NOTE]
A minimum of three Novus Data Directors is required for a supported deployment. Each must be in a separate failure domain to ensure high availability and fault tolerance. Contact your NetApp account team to determine the right number of AFF A90 for Novus systems and NDD servers for your environment and workload.

Host platform summary::
A server the customer or a partner provides that meets NetApp Novus hardware and firmware configuration requirements. The hosts need to run RHEL 9 with NVMe drives in RAID1 (2 drives) or RAID10 (4 to 12 drives).

Linux and NFS::
Red Hat Linux 9.8 with NFSv4 (v4.2); pNFS must be enabled and properly configured.

Minimum cluster deployment::
Three Novus Data Directors in three separate failure domains supporting at least one ONTAP HA pair. Each tenant has its own database cluster with three copies of the data (one on each host).

Networking::
Each tenant is isolated on its own VLAN and VRF.

== Novus clients

The NFS flexible file layout is supported using standard NFS clients available with Ubuntu 24.04 and later as well as Red Hat Linux 9.8 and later. For a flexible file layout with striping, only the NFS client on Ubuntu 26.04 is supported.
