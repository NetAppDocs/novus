= Example of a Novus storage system deployment
:icons: font
:imagesdir: ../media/

[.lead]
A Novus storage system can be deployed in several different configurations depending on your performance and capacity requirements. Here's a simple deployment example.

== Storage cluster connectivity

Deployments with 1024 GPUs require a total of three AFF A90 for NetApp Novus storage systems and three Novus Data Director (NDD) servers to meet the standard performance requirements for current-generation GPUs.
