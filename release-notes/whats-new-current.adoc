== Novus initial release

NetApp Novus is a storage solution built on a new architecture based on Parallel NFS (pNFS) with ONTAP data servers. It's designed for leading-edge throughput and low latency to meet the requirements of customers with exascale computing and gigawatt-scale AI factories.
